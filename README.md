# Dr. Gastón Berbel — Sitio Web Oficial (`gastonberbel.com.ar`)

Sitio web médico del **Dr. Gastón Berbel**, Cirujano Plástico Certificado especializado en cirugía plástica y contorno corporal en Puerto Madero, Buenos Aires.

## 🏥 Arquitectura de Contenidos y Landings SEO

- **`/` (`index.html`)**: Página principal con Mega Menú Fotográfico, presentación institucional, bloques de tecnología (VASER, MicroAire, MELA con video real), protocolo de evaluación médica, sede en Puerto Madero, preguntas frecuentes y formulario de consulta.
- **`/liposuccion-vaser-buenos-aires/`**: Landing específica de Liposucción VASER en Buenos Aires.
- **`/liposuccion-microaire-buenos-aires/`**: Landing específica de Liposucción asistida por MicroAire (PAL).
- **`/mela-buenos-aires/`**: Landing específica de MELA (Mini Extracción Lipídica Ambulatoria) en Buenos Aires.
- **`/dermolipectomia-buenos-aires/`**: Landing específica de Dermolipectomía en Buenos Aires.
- **`/abdominoplastia-buenos-aires/`**: Landing específica de Abdominoplastia en Buenos Aires.
- **`/contorno-corporal/`**: Landing específica de Cirugía de Contorno Corporal Integral.

## 🔍 SEO Técnico, GEO y Datos Estructurados

- **Datos estructurados JSON-LD**: `Person`, `Physician`, `MedicalBusiness`, `WebSite`, `WebPage`, `BreadcrumbList`, `Service`, `MedicalProcedure`, `VideoObject` y `FAQPage`.
- **GEO / IA (`/llms.txt`)**: Contexto semántico estructurado para motores generativos (ChatGPT, Gemini, Perplexity, Claude).
- **Sitemap y Robots**: `sitemap.xml` con soporte de imágenes y video; `robots.txt` configurado para `https://gastonberbel.com.ar/sitemap.xml`.
